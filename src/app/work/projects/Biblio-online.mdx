## Description

Biblio Online est une application web moderne développée avec React + Vite, permettant aux utilisateurs de gérer leur bibliothèque personnelle en ligne de manière simple et intelligente.
Grâce au scan de code-barres, un livre peut être automatiquement ajouté à la bibliothèque avec ses informations principales. L’utilisateur peut ensuite suivre l’état de lecture (lu, en cours, à lire), le nombre de pages restantes et son avancement.

La plateforme permet également la recherche de livres par nom ou code-barres, l’organisation complète de la bibliothèque, ainsi que l’affichage de statistiques récapitulatives et de recommandations personnalisées basées sur les habitudes de lecture.

## Objectifs

- Centraliser la gestion d’une bibliothèque personnelle en ligne
- Automatiser l’ajout de livres via scan de code-barres
- Offrir une interface moderne, fluide et responsive
- Permettre le suivi de lecture et de progression utilisateur
- Fournir des statistiques et recommandations intelligentes

## Fonctionnalités et Techniques

- Gestion de bibliothèque numérique : Ajout, modification, suppression et organisation des livres
- Scan de code-barres : Reconnaissance automatique et récupération des données livres
- Recherche intelligente : Recherche par titre, auteur ou ISBN/code-barres
- Suivi de lecture : Statut (lu, en cours, à lire), pages restantes, progression dynamique
- Dashboard personnel : Vue globale de la bibliothèque, statistiques et indicateurs de lecture
- Système d’authentification sécurisé : Inscription, connexion, profils utilisateurs
- Recommandations de livres : Suggestions basées sur l’historique et les préférences
- Interface moderne : UI fluide, responsive design, navigation rapide avec React
- Architecture conteneurisée : Déploiement et environnement isolé via Docker

## Compétences Démontrées

- Frontend : React, Vite, JavaScript ES6+, HTML5, CSS3
- Backend : API Node.js / Express
- Base de données : PostgreSQL
- Conteneurisation : Docker, Docker Compose
- Outils de développement : Git, VSCode
